📖 Guide d'utilisation FORM

1. Choisir un backend

☁ Tripo3D (cloud, payant)

Génération en quelques secondes/minutes via l'API Tripo. Meilleure qualité pour les visages et formes complexes. Nécessite une clé API.

  1. Crée un compte sur platform.tripo3d.ai
  2. Génère une clé API (commence par tsk_)
  3. Colle-la dans le panneau gauche (zone "Clé API Tripo3D")
  4. Tarif : ~10-50 crédits par génération selon la qualité
🟣 TRELLIS Local (gratuit, GPU NVIDIA requis)

Génération 100% locale, gratuite, illimitée. Bon pour les objets, moyen pour les visages humains.

  1. Installe le fork IgorAherne/TRELLIS.2-stableprojectorz
  2. Lance l'API : python -m uvicorn api_spz.main_api:app --host 127.0.0.1 --port 7960
  3. Bascule sur "TRELLIS Local" dans la barre du haut
  4. Le point doit passer 🟢 vert quand le serveur répond

2. Choisir ton imprimante (panneau Filaments)

Va dans l'onglet Filam. à droite, choisis ton modèle Bambu Lab. La X2D est sélectionnée par défaut. Tous les calculs (vitesse, temps, fit du plateau) s'adaptent automatiquement.

4 modes de génération

📝 Texte

Décris ton objet en français ou anglais. Plus le prompt est précis, mieux c'est. Exemple : "figurine cyberpunk de samouraï, armure noire mate avec néons cyan, posée sur un socle hexagonal, style low-poly".

Astuce : ajoute un prompt négatif pour exclure (texte, logos, flou).

🖼 Image

1 image (JPG/PNG). Préférer une image frontale, nette, bien éclairée, fond neutre. Les objets posés à plat fonctionnent mieux que les angles bizarres.

📐 Multi-view (4 angles)

Le meilleur pour les modèles complexes. Ordre obligatoire : Face → Gauche → Dos → Droite. Si tu n'as qu'une image, clique "✨ Générer 4 vues" — l'IA Tripo crée les 3 autres angles automatiquement.

🔀 Hybride

Image + description. Idéal pour orienter le style depuis une référence visuelle.

Qualité Tripo

  • Turbo · ~10 cr · 15s · qualité moyenne, pour tester
  • Standard · ~20 cr · 2 min · bon compromis
  • HD · ~40 cr · 5 min · ★ qualité maximale (recommandé pour impression)

Presets TRELLIS

3 boutons en haut du panneau TRELLIS : Rapide (test), Équilibré (défaut), Qualité Max (1536³ + 50/50 steps + 100k poly + tex 4096 + guidance 9.5).

Pour les visages humains

  1. Clique 👤 Preset Visages humains (panneau Qualité Tripo) → force HD + Multi-view
  2. Upload 4 photos (face, gauche, dos, droite) nettes et bien éclairées
  3. Génère
  4. Une fois prêt → clique ⬆️ Raffiner HD dans la barre de post-processing (en bas du viewer) → 2ème passe qui améliore visiblement les visages
⚠️ TRELLIS est fondamentalement moyen sur les visages humains. Pour les personnages, préfère toujours Tripo.

Post-processing (après gen Tripo)

  • ⬆️ Raffiner HD — repasse en HD, améliore géométrie + textures
  • 🔺 Low-poly — réduit les polys pour impression rapide ou jeu
  • 🧱 Lego / 📦 Voxel / 🕸 Voronoi — stylisations
  • ✂️ Segmenter — découpe en parties séparées (utile pour multi-couleur ou pièces détachables)
  • 🦾 Rigger — ajoute squelette + animations (export GLB/FBX)
  • 🎨 Re-texturer — applique un nouveau style via prompt

Pour des objets propres pour impression 3D

  • Active toujours Base plate (fond plat)
  • Active Auto-orient
  • Privilégie Multi-view plutôt que Image simple
  • Mode TRELLIS : active Watertight (fermeture des trous — obligatoire pour impression)

Bambu Studio — Formats acceptés

Bambu Studio importe : 3MF · STL · STEP · SVG · OBJ · AMF. Il n'importe PAS le GLB.

Quel format choisir ?

FormatCouleurCoûtUsage
3MF ★✓~10 cr★ Recommandé impression — Bambu Studio + AMS multi-couleur
STL✗~10 crBambu / Orca / Prusa — sans couleur
OBJ✓ (MTL)~10 crBambu compatible · couleur via fichier MTL
GLB✓GratuitPas pour Bambu — Blender, Unity, Web, conversion locale
FBX✓~10 crAnimation — Maya, 3dsMax, Unity
💡 Pour imprimer directement avec couleurs sur Bambu → 3MF (~10 cr). Pour économiser les crédits → exporte GLB gratuit et convertis localement avec Blender.

⚡ Export local gratuit (recommandé) — 1 clic

🟢 STL local & OBJ local — directement dans FORM

FORM convertit le mesh Three.js en STL/OBJ directement dans ton navigateur, sans appel API, sans crédit :

  1. Génère ton modèle (Tripo ou TRELLIS)
  2. Onglet Export à droite → section 🆓 Conversion locale
  3. Clique STL local ou OBJ local → téléchargement instantané
  4. Importe dans Bambu Studio

Limitation : sans couleur sur STL · OBJ exporte la géométrie + UV mais pas les matériaux PBR. Pour la couleur complète sur Bambu (AMS), utiliser 3MF (~10 cr) ou OBJ Tripo.

🔧 Convertir GLB → STL via Blender (alternative)

  1. Télécharge Blender (gratuit) : blender.org
  2. Dans FORM : export GLB (gratuit)
  3. Ouvre Blender → File → Import → glTF 2.0 → sélectionne ton .glb
  4. File → Export → STL (ou Wavefront OBJ pour garder la couleur)
  5. Importe le STL dans Bambu Studio
⚡ Alternative : convertisseurs en ligne

Si tu n'as pas Blender, ces convertisseurs gratuits acceptent GLB :

  • anyconv.com/glb-to-stl
  • imagetostl.com (glb→stl)
  • aspose.app (glb→stl)

⚠️ Ces sites uploadent ton mesh sur leurs serveurs — pour des modèles confidentiels, préfère Blender en local.

🎨 Préserver les couleurs/textures

Pour conserver les couleurs/textures à l'impression :

  • 3MF (via FORM, ~10 cr) — natif Bambu Studio multi-couleur
  • OBJ + MTL (via FORM, ~10 cr) — Bambu Studio lit le fichier MTL
  • GLB → OBJ via Blender (gratuit) — exporte avec "Materials" coché

STL ne supporte aucune couleur — c'est juste une géométrie.

TRELLIS Local

Export GLB uniquement (généré localement, gratuit). Pour imprimer : convertis en STL/OBJ via Blender ou un convertisseur en ligne, puis importe dans Bambu Studio.

1. Configurer le profil dans FORM

  1. Onglet Filam. (à droite)
  2. Choisis ton imprimante Bambu (X2D par défaut)
  3. Choisis ta buse (0.4 mm est le défaut)
  4. Choisis le matériau (PLA, PETG, ABS…)
  5. Ajuste le prix au kg si besoin

2. Lire les Specs

Onglet Specs à droite → tu vois ~40 paramètres calculés pour ton imprimante et ton matériau : temps d'impression, températures, vitesses, supports, coûts.

Clique Copier les specs en bas → tout est copié dans le presse-papier en format texte, prêt à coller dans Bambu Studio.

3. Imprimer

  1. Export GLB (gratuit)
  2. Drag&drop dans Bambu Studio
  3. Applique les paramètres du panneau Specs (couches, vitesses, support, ventilation)
  4. Bambu Studio gère l'orientation + supports automatiquement
  5. Pour les multi-couleur : utilise 3MF + AMS (X2D / X1 / P1S / A1)

4. Ouverture directe Bambu Studio

Bouton 🎯 Bambu Studio dans l'onglet Export → tente d'ouvrir le modèle dans Bambu via le protocole bambu-studio://. Marche si Bambu est installé localement.

❓ Mes crédits Tripo s'épuisent vite

Export en GLB (gratuit) puis convertis localement avec Blender (gratuit aussi) : File → Import glTF 2.0 → File → Export STL. Voir l'onglet Export pour le workflow détaillé.

❓ Bambu Studio n'importe pas mon GLB

Normal — Bambu Studio n'accepte pas le GLB. Formats supportés : 3MF, STL, STEP, SVG, OBJ, AMF. Soit tu exportes directement en 3MF/STL/OBJ depuis FORM (~10 cr), soit tu convertis ton GLB localement via Blender (gratuit).

❓ Les visages sont moches

Voir l'onglet ★ Qualité. Résumé : Tripo HD + Multi-view + Raffiner HD.

❓ TRELLIS ne se connecte pas

Vérifie que le serveur tourne :

  1. http://127.0.0.1:7960/ doit renvoyer {"status":"ready"}
  2. Lance avec : python -m uvicorn api_spz.main_api:app --host 127.0.0.1 --port 7960
  3. Active le venv avant : .\venv\Scripts\Activate.ps1
  4. Le point à côté de "TRELLIS Local" passe vert quand l'API répond

❓ L'historique ne marche plus

Les modèles sont stockés en IndexedDB du navigateur. Si tu as effacé les données du site, c'est perdu. Sinon, clique sur un item de l'historique pour le recharger.

❓ Le fichier exporté n'a pas d'extension

Plus possible — depuis la PR #13, tous les downloads passent par un blob URL local avec extension forcée.

❓ Mon modèle est trop grand pour mon imprimante

Un warning orange apparaît dans Specs. Utilise le slider d'échelle en haut du viewer pour réduire (10-400%).

❓ Supports nécessaires ou pas ?

Section Supports dans Specs → calcul automatique des overhangs > 45°. Si > 5% de faces en surplomb, Tree supports sont recommandés.

❓ Bouton "Bambu Studio" ne fait rien

Bambu Studio doit être installé localement et avoir enregistré le protocole bambu-studio://. Si ça ne marche pas, télécharge le GLB et drag&drop manuellement dans Bambu.
